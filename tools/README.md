# Инструменты настройки вида

Это рабочие инструменты, они не часть сайта. С сайта на них нет ссылок. Страницы `ui-kit.html` и `life-selected-ideas.html` закрыты от поисковиков.

## Что здесь лежит

- `tune-panel.js` — панель «Настройка вида». Меняет цвета, текст, подложки, тени, рамки, шум, размеры текста и вид выбранной строки слева прямо на открытой странице. Есть инспектор текста (наведите на текст, и подсветятся такие же стили), глазик для сравнения с оригиналом и кнопка «Копировать значения».
- `ui-kit.html` — отдельная страница с палитрой, размерами текста, кнопками, тегами, списками и картинкой на подложке. Токены можно менять, внизу есть аудит значений на сайте.
- `life-selected-ideas.html` — первые шесть вариантов выделения выбранной строки слева.

## Как подключить панель

Добавьте строку перед `</body>` нужной страницы и не коммитьте её.

```html
<script src="tools/tune-panel.js"></script>
```

Панель появится справа внизу. Её можно двигать за шапку. Настройки хранятся в браузере. Ссылки на другие страницы в превью перехватываются, чтобы окно просмотра их не ломало, поэтому в обычном браузере для перехода открывайте страницы напрямую.

## Заметки

- Раздел «Режим просмотра картинок» в панели работает с цветами окна просмотра (токены `--lb-*`). Эти цвета пока лежат в ветке `claude/getting-started-phet50` и в `main` не перенесены.
- Значения по умолчанию в панели совпадают с тем, что сейчас на сайте. «Копировать значения» выдаёт текст, который можно прислать для переноса на сайт.
